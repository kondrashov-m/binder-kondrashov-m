## Зачем

На Service Desk в течение смены легко взять заявку в работу и забыть про неё. BINDER делает это видимым:
каждая заявка, которую ты начал, висит в левой колонке с идущим таймером, пока ты её не закроешь.
Ближе к концу смены программа сама напомнит, что ещё осталось.

## Возможности

**Заявки**
- Две колонки: **«Заявки в работе»** и **«Выполнены»**, каждая заявка показана отдельной карточкой.
- Вводишь номер заявки и, по желанию, описание («что делаю»), затем жмёшь Enter или «В работу».
- Таймер у заявки в работе идёт, а индикатор пульсирует. У выполненной заявки таймер остановлен.
- Время считается по системным часам и идёт, даже если программа закрыта или компьютер выключен.
- Перенести заявку в «Выполнены» можно галочкой на карточке или перетаскиванием мышью. Так же её можно вернуть обратно.
- Двойной клик по карточке открывает редактирование номера и описания.
- Правый клик открывает меню: выполнено / вернуть, изменить, скопировать номер, удалить.
- Кнопка «очистить» переносит выполненные заявки в `rtbind_history.txt` с датой, временем взятия, закрытия и затраченным временем. Получается готовый отчёт за смену.

**Напоминание**
- Каждый день в заданное время в углу экрана всплывает окно со списком незакрытых заявок.
- Напоминание можно включить или выключить и выбрать время. Кнопка **ТЕСТ** показывает его сразу.
- Если все заявки закрыты, напоминание не появляется.

**Бинды**
- **Ctrl+F1 … Ctrl+F12** печатают заготовленный текст в активное окно (например, стандартные фразы для протоколов в OmniTracker).
- Фразы редактируются прямо в программе, кнопка **«Бинды»**, или в файлах `binds\F1.txt … F12.txt`.
- Текст вводится как Unicode-символы, поэтому раскладка не важна, а буфер обмена не трогается. Многострочный текст тоже работает.

## Установка

Ничего устанавливать не нужно.

1. Скачай [`release/RTBind.exe`](release/RTBind.exe).
2. Положи его в отдельную папку, например `Рабочий стол\rtbind`.
3. Запусти.

Рядом с exe программа создаст свои файлы:

| Файл / папка | Что хранит |
|---|---|
| `rtbind_data.txt` | текущие заявки |
| `rtbind_history.txt` | архив выполненных заявок |
| `rtbind_settings.txt` | настройки напоминания |
| `binds\F1.txt … F12.txt` | тексты биндов (UTF-8; ANSI/UTF-16 тоже читаются) |

Чтобы перенести программу на другой компьютер, скопируй папку целиком.

> Windows SmartScreen может предупредить о неизвестном издателе. Нажми «Подробнее» → «Выполнить в любом случае».

## Совместимость

- Windows 7 SP1, 8, 8.1, 10, 11, 32- и 64-битные.
- Чистый WinAPI на C, без CRT, .NET, Python, браузерного движка и сторонних DLL.
  Используются только системные `kernel32`, `user32`, `gdi32`, `msimg32`, `shell32` и `comctl32`.
- Поддерживается масштаб экрана (DPI).

## Сборка из исходников

Исходники лежат в `src/`, ресурсы (иконка, манифест, версия) в `res/`, а списки импортируемых функций WinAPI в `build/defs/`.
Windows SDK и Visual Studio не нужны, достаточно LLVM.

**Windows** (LLVM: `winget install LLVM.LLVM`):
```bat
build\build.bat
```

**Linux / WSL** (`apt install clang lld llvm`):
```bash
./build/build.sh
```

Результат будет в `out/RTBind.exe`.

## Структура

```
src/        rtbind.c — вся программа, w32.h — минимальные объявления WinAPI
res/        иконка, манифест (DPI, стили Windows), информация о версии
build/      скрипты сборки и .def-файлы для импорта системных DLL
docs/       картинки для README
release/    готовый RTBind.exe
```
